# OrderPilot UI reference

`orderpilot-main-workspace.png` is the implementation reference for the first-version desktop workspace.

It follows the approved product scope:

- a fixed, searchable store sidebar;
- masked Admin API Token status with a replacement action when credentials expire;
- concrete product-variant selection and per-order quantity;
- existing, manual, or absent customer modes;
- `PENDING` as the visible default payment status;
- a separate batch count and a review-before-create action;
- concise recent-batch status without an analytics dashboard.

The image is a visual reference, not a source of behavioral requirements. The design specification and domain types remain authoritative for validation, state transitions, and Shopify behavior.
